**玄幕安全团队-guaidao2** 出品

FakeAGI 是一个基于自维持哲学的通用认知架构实验性实现。它没有外部奖励函数，没有预训练阶段，不依赖大语言模型——它只是在活着，并在这个过程中展现出智能。

---

## 核心理念

智能不是解决问题的能力。智能是系统维持自身存在的能力。

当前所有主流 AI 路线都问同一个问题："我要如何完成这个任务？"FakeAGI 问的是另一个问题："我要如何继续存在？"

完整的哲学推导见 [`PAPER.md`](PAPER.md)。

下一代进化架构（MoE 专家路由 + 经验 DNA 跨代）见 [`EVOLUTION.md`](EVOLUTION.md)。

## 架构概览

```
五层认知（反射→学习→规划→想象→元认知）
        ↓
人脑式决策委员会（5决策者并行投票 + 加权仲裁）
        ↓
三层循环（自我层→认知层→物理层）
        ↓
增量神经元生长（每次+8，稀疏连接，权重迁移）
        ↓
十条哲学公理（物质-信息 → 价值注入）
```

## 技术栈

- **时序推理**：液体时间常数网络（LTC），τ ∈ [1, 50] 自适应
- **决策**：人脑式决策委员会 —— 反射/边缘/习惯/规划/元认知 5 路并行投票，加权仲裁，冲突→深思模式，危急→恐慌模式
- **世界模型**：条件预测（hidden+action→next_hidden），误差通路选择（感知/行动）
- **薛定谔叠加态世界模型**：多分支未来叠加（波函数）→ 观测坍缩（振幅更新）→ 残余熵=量子化惊奇 → 容量不足自动分裂新分支（随世界复杂度生长，A/B 显示学习快 39%）
- **P6 感知器官生长**：高维输入自动长出感知器官 —— 超量生成 3 候选 → 竞争期候选输出真实替换观测流（世界模型误差=感知质量）→ 最优保留其余凋亡 → 成熟器官可复制/变异/修剪（结构级生长，不只是扩维）
- **语言器官（符号接地）**：词的意义=预测收益 —— token 嵌入 → 语言向量拼入观测 → 接地训练（词→状态）→ 说话（内部状态→词，`word_probe`）。默认关闭，`config.language=True` 开启
- **语言生存压力（P8a）**：可信度驱动的语言使用（`_language_trust` 强化/坍缩/试探）——当语言成为生存必要通道（食物方向隐藏）时系统真正理解语义（对照组饿死 vs 语言组存活 4.3 倍）
- **语言意图（P8b）**：主动说话（`AGI.speak()` 需求驱动：说话概率=需求×信任）+ 意图优先仲裁（指令加成压过反射）——系统用语言达成目的（会说满存活 vs 不会说饿死）
- **目标层（L1）**：目标 vs 过程分离（`core/goals.py`）——持久目标表征 + 落差 = 目标−当前（驱动信号）
- **信息寻求（E13）**：`core/info_seeking.py` 定向扫掠（有记忆系统性搜索）——落差门控启动，5 倍于随机探索（n=3 弱支持）
- **过程选择（②）**：`core/process_selector.py` 语言×目标层统一——可靠性在线估计 + argmax 选择（问路 vs 扫掠），V1-V4 + N1-N4 验证通过（n=5）
- **叠加态可靠性（C2）**：`SuperpositionEstimator` 多假设+贝叶斯坍缩+置信度地板——被教歪可逆（不单点信任），4 项验证 + n=30 回归全过
- **他者模型**：`core/other_agent.py` 真他者跟踪——意图分类（竞争/合作）+ 竞争回避，多智能体实验 5 项全过
- **情绪系统**：`core/emotion.py` 显式情绪信号（恐惧/好奇/平静——生理+认知复合）+ 决策调制，5 项验证全过
- **能力落地（③）**：情绪 + 他者接入主循环（默认关闭开关），接入验证 4 项全过
- **句法层（P8c）**：`cognition/language/syntax.py` 词序学习 + 短语组合（可学习语法，非硬编码），4 项验证全过
- **跨域迁移（④）**：`core/cross_domain.py` 底层能力提取 + 全模型微调——**诚实负结果**（迁移不占优 0.97x/0.86x，初版 7 倍为堆牌已废弃；骨架保留，待更合适任务对）
- **触类旁通（⑤）**：`test_transfer_analogy.py` 策略层迁移（关系同构域对：迷宫墙→威胁场）——**少样本迁移成立（37vs20）**，零样本不成立（初版"17vs0"为停留基线伪胜利已修正）
- **迁移价值评估（⑥）**：`core/transfer_selector.py` 何时迁移的元认知——多假设贝叶斯+幅度加权，同构升/异构降/未知域选对（5 项全过）；已接入主循环（环境切换决策，默认关闭）
- **全模块协同（E14）**：`test_emergent.py` 语言+情绪+他者全开迷宫世界——5 项全过（多模块激活+语言联动+协同不拖累），暴露睡眠未触发集成短板
- **生长**：增量式神经元生长（每次 +8，稀疏突触连接，tau/encoder/bias 权重迁移），输入维度自动扩展
- **元认知**：知识缺口检测 + 探索目标生成 + 反射压制 + 学习策略切换
- **价值进化**：核心价值（存续优先）不可变，次级价值（好/坏判断）由经验调整
- **物理直觉**：物理先验置信度（贝叶斯式经验修正），瞬移检测→应激

## 设计原则

1. **无外部奖励** — 唯一的训练信号是预测误差
2. **自维持优先** — 所有模块服务于存在概率最大化
3. **持续在线学习** — 无训练/部署割裂，AGI 是"活"出来的不是训练出来的
4. **增量生长** — 神经元每次少量新生，旧知识权重迁移保留
5. **并行决策** — 多决策系统竞争+加权仲裁，而非单一模块顺序覆盖
6. **五层耦合** — 反射→学习→规划→想象→元认知
7. **结构生长** — 不只是扩宽已有通路；遇到新模态自动长出新的感知结构（器官生成器）
